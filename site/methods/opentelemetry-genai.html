OpenTelemetry GenAI 調用追蹤

以模型調用紀錄找出 token 消耗發生在哪個工作步驟。

原作者怎麼做

  • 以 GenAI 語意慣例記錄模型調用和可取得的輸入、輸出 token 數。
  • 用追蹤紀錄把同一工作中的模型與工具呼叫放在一起看。若系統有記下重試，便可檢查異常是否來自重複調用。
  • 用調用資料解釋用量變動；實際帳務另外和供應商費用資料核對。

適用範圍

適合需要從總費用追到個別任務的團隊。對帳是本站整理的應用方式，實際能追到多少取決於使用的工具及埋點。

這個方法可用在哪些問題

  • 每件通過驗收的工作用了多少 token、花了多少錢？換一種做法會更有效率嗎？
  • 怎麼監控日常 token 用量和費用，發現異常時誰來查？
