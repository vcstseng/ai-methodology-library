Microsoft Agent CoE 的角色與責任

把服務維護、日常支援與員工培訓分配給明確的角色。

原作者怎麼做

  • 服務負責人對正式營運的可靠性和升級處理負責。
  • 平台與營運團隊負責監控、支援和事件處理。採用負責人負責培訓與溝通，Champions 則協助同事上手。
  • 用文件提供的 RACI 範例區分執行者、最終負責人、諮詢者和應知會的人。

為什麼收在這一題

適合對照誰負責哪一類工作。若要確認備援人員能獨立接手，可接著看操作手冊與實際演練。 查看 AWS Runbooks。
