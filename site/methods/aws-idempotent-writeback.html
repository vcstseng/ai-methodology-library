AWS 的安全重試與回寫

讓相同工作重試時能被目的系統識別，避免重複寫入。

原作者怎麼做

  • 讓呼叫方為一次操作指定唯一識別碼，同一意圖重試時重用它。
  • 目的系統依呼叫方和識別碼辨認重複請求，並把識別碼紀錄和寫入一起處理。
  • 讓重試能取回意義相同的結果，降低逾時後無法確認是否已寫入的問題。

為什麼收在這一題

這是 API 整合做法。目的系統若不支援，呼叫方不應只靠重試；先查詢實際狀態，或交由人確認。
