OpenAI 的人工接手觸發條件

設定重試上限和高風險操作的人工介入條件。

原作者怎麼做

  • 先定 agent 重試或嘗試行動的上限。
  • 超過上限或仍無法判斷使用者需求時，移交給人。
  • 對敏感、不可逆或高影響操作保留人工介入。

為什麼收在這一題

適合設計工作卡住時的接手點。限制次數與高風險的定義要按工作和組織規則設定。
