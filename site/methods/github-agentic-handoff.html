GitHub Agentic Workflows 的人工審查與合併

讓 AI 交付可查核的變更提案，由另一位人員依儲存庫規則覆核。

原作者怎麼做

  • 把 AI 產出送成變更提案，和原始工作需求連在一起。
  • 保留變更內容、必要的檢查結果、核准與合併紀錄。
  • 由另一位人員依既有變更規則審查，符合條件後才合併。

為什麼收在這一題

原文針對軟體變更。把提案、佐證和放行點放在一起，是這題可借用的地方。未通過時的修正流程由儲存庫或組織規則決定。
