Anthropic 的多 agent 研究系統

由主 agent 分派可獨立的研究方向，子 agent 交回成果或參照。

原作者怎麼做

  • 由主 agent 說明子任務目標、範圍、可用工具及交付格式。
  • 把可獨立探索的方向交給不同子 agent。
  • 需要時讓子 agent 把成果寫到外部位置，再回傳簡短參照供主 agent 整合。

為什麼收在這一題

這是研究產品的實作紀錄，最適合可平行探索的工作。原文的成效不能直接套用到有強依賴或共用寫入的流程。
