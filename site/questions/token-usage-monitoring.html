營運與演進

怎麼監控日常 token 用量和費用，發現異常時誰來查？

按流程追蹤用量與費用，分辨是工作量增加、單件變貴，還是反覆重試。

可參考的做法

2 個方法

  • 異常交給誰查

    FinOps Anomaly Management

    帳單突然上升時，先按服務、專案或成本標籤把異常對到負責團隊。FinOps Foundation 建議由 FinOps 和各團隊訂告警規則，再由掌握該流程的工程團隊查原因，並記錄怎麼處理。

  • 查出用量怎麼變

    OpenTelemetry GenAI 調用追蹤

    如果帳單只能告訴你花了多少，可用 OpenTelemetry 記錄模型、輸入與輸出 token，並把一個任務內的多次呼叫串起來。把任務量和調用紀錄一起看，才有機會分辨是案件變多，還是某個步驟開始多次呼叫。

適用範圍

相關問題：每件合格成果的 token 與成本怎麼算？

單次調用的 token 紀錄有助於定位問題。實際費用還要對照供應商帳單與費率，並留意同一流程的重試是否都有被記錄。
