流程與分工

多個 AI 一起做事時，怎麼分工、共享資訊和交接？

釐清每個角色讀取與交付的內容，以及誰負責處理彼此的衝突。

可參考的做法

2 個方法

  • 先選交接與合併方式

    Azure 的多 agent 協作模式

    如果步驟有固定先後，用循序交接；如果子任務能獨立進行，可平行處理，再由指定角色匯整。Azure 的指引也提醒，先決定哪些資訊要共享、誰檢查下一步的輸入，以及結果矛盾時怎麼處理。

  • 給子 agent 清楚任務與獨立交付物

    Anthropic 的多 agent 研究系統

    如果研究可拆成幾個互不依賴的方向，可以參考 Anthropic 由主 agent 分派範圍和交付格式、子 agent 保留成果並交回連結的做法。主 agent 負責整合，不必把所有中間內容反覆傳給每個角色。

適用範圍

單一 agent 或固定流程能完成時，先用較簡單的設計。若平行結果有衝突，應事先指定合併規則或誰需要人工裁決。
