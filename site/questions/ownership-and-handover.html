營運與演進

誰負責維護、培訓和交接？關鍵人員離開時，誰能接手？

把流程寫成可交接的操作說明，並讓備援人員實際走一次。

可參考的做法

2 個方法

  • 分配責任

    Microsoft Agent CoE 的角色與責任

    如果原本由同一人維護、教同事和處理異常，可以用 Microsoft 的責任表把工作拆開。服務負責人管正式營運和升級處理，平台與營運團隊管監控及支援，採用負責人則安排培訓。

  • 驗證接手能力

    AWS Runbooks

    有了備援人員後，可以用 AWS 的做法檢查交接是否真的可行。把工具、權限、預期結果和出錯時的處理方式寫進操作手冊，請另一位同事照著跑一次，再補上他卡住的步驟。

適用範圍

責任表能說清楚誰接手。實際走過的操作範圍，才是這次交接驗證能支持的範圍。
